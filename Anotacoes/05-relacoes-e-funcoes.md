# Relações e Funções

## 1. O que é uma relação?

Uma relação matemática descreve associações entre elementos de conjuntos.

Uma forma de representar uma relação é utilizando pares ordenados, escritos como \((a,b)\).

**Exemplo:**

Considere os conjuntos:

\[
A=\{1,2,3\}
\]

\[
B=\{2,4,6\}
\]

Podemos definir a relação:

\[
R=\{(1,2),(2,4),(3,6)\}
\]

Isso significa que o elemento 1 está relacionado com 2, o elemento 2 está relacionado com 4 e o elemento 3 está relacionado com 6.

## 2. Produto cartesiano

O produto cartesiano de dois conjuntos A e B, representado por \(A\times B\), é o conjunto de todos os pares ordenados em que o primeiro elemento pertence a A e o segundo pertence a B.

Considere:

\[
A=\{1,2\},\quad B=\{a,b\}
\]

Então:

\[
A\times B=\{(1,a),(1,b),(2,a),(2,b)\}
\]

Como A possui 2 elementos e B possui 2 elementos, o produto cartesiano possui:

\[
2\times2=4
\]

pares ordenados.

## 3. O que é uma função?

Uma função é uma relação em que cada elemento do domínio está associado a exatamente um elemento do contradomínio.

Podemos representar uma função por:

\[
f(x)=2x
\]

Isso significa que a função multiplica o valor de entrada por 2.

**Exemplo:**

Para \(x=3\):

\[
f(3)=2\times3=6
\]

Para \(x=5\):

\[
f(5)=2\times5=10
\]

Cada valor de entrada possui uma única saída.

## 4. Domínio, contradomínio e imagem

- **Domínio:** conjunto de valores de entrada da função.
- **Contradomínio:** conjunto definido como destino dos resultados.
- **Imagem:** conjunto dos valores que a função realmente produz.

Considere a função \(f(x)=2x\), com domínio:

\[
A=\{1,2,3\}
\]

E contradomínio:

\[
B=\{2,4,6,8\}
\]

Calculando os valores:

\[
f(1)=2,\quad f(2)=4,\quad f(3)=6
\]

Logo, a imagem é:

\[
Im(f)=\{2,4,6\}
\]

O número 8 pertence ao contradomínio, mas não pertence à imagem dessa função com o domínio definido.

## 5. Como identificar uma função?

Cada elemento do domínio precisa ter exatamente uma saída.

Considere a relação:

\[
R=\{(1,2),(2,4),(3,6)\}
\]

Ela representa uma função, pois cada primeiro elemento aparece associado a apenas um resultado.

Agora considere:

\[
R=\{(1,2),(1,3),(2,4)\}
\]

Essa relação não representa uma função de A para B se o domínio contém o elemento 1, pois 1 está associado a dois resultados diferentes: 2 e 3.

## 6. Aplicação na computação

Funções matemáticas podem representar cálculos e transformações realizadas por programas. Por exemplo, uma função pode calcular o dobro de um número, converter temperaturas ou determinar o preço final de um produto.

## 7. Conclusão

As relações descrevem associações entre elementos. As funções são relações especiais nas quais cada entrada possui exatamente uma saída. Domínio, contradomínio e imagem são conceitos fundamentais para compreender como as funções são definidas e utilizadas.
