# Matemática para computação

Este repositório tem como objetivo reunir e organizar os conteúdos estudados na disciplina de Matemática para Computação durante a graduação em Ciência da Computação.

## Objetivo

Registrar e organizar os conhecimentos adquiridos ao longo da disciplina, facilitando a consulta, a revisão dos conteúdos e o acompanhamento das atividades desenvolvidas.

## Conteúdos

O repositório será atualizado conforme o avanço da disciplina, reunindo anotações, exercícios resolvidos, cálculos e materiais relacionados aos assuntos estudados.
